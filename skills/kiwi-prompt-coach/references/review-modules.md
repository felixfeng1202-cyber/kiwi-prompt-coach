# Prompt 模式审查

仅在 Prompt 模式使用。根据复杂度合并，避免机械跑满流程。

1. **目标、输入与成功标准**：结果是否具体，必要上下文、证据和验收标准是否完整。
2. **最小充分性**：角色、步骤、示例和限制是否真的改变结果；能删的先删。
3. **行动与工具边界**：回答、建议和实际执行是否分清；权限、停止和失败条件是否足够。
4. **输出契约**：必须保留什么、优先删什么；风格要求是否可观察，而非抽象形容词。
5. **代表性试跑**：用真实或接近真实的场景验证，确认规则可跨模型理解后再交付。

富简报或简单需求可一次完成审查。只有反馈会明显改变结果时才继续追问；用户明确接受当前版本时直接交付。
