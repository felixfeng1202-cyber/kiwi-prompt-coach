# 草案与格式

## Prompt 草案模板

仅在 Prompt 模式使用：

```markdown
## 当前草案 - V1
## 目标
[具体结果]

## 上下文与输入
[必要背景、变量和素材]

## 交付与成功标准
[必须交付什么；怎样算正确]

## 工作与权限边界
[仅在多步骤、工具或行动型任务中填写]

## 输出契约
[必须包含的内容、结构和长度优先级]

## 必要限制
[安全、合规和关键业务禁区]

## 示例
[只有能带来可验证收益时填写]
```

删除空章节。角色只有在专业视角或语气确实影响结果时才加。

Skill 模式不套用这份 Prompt 模板；使用 `skill-mode.md` 的 Skill 合同。

## 版本与展示

- 草案更新时递增版本号。
- Skill 端到端模式默认在内部维护合同，不要求用户逐版确认；只有存在重要推断或用户要求时才展示。
- 最终产物删除版本变化、协商记录和修改理由。

## 嵌套代码块

草案内没有代码块时，外层使用三反引号；草案内含三反引号代码块时，外层改用四反引号。长或嵌套复杂的产物直接写入文件并交付，避免破坏 Markdown 渲染。
