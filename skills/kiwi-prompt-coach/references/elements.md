# Prompt 模式要素

仅在交付独立 Prompt 时使用，并与 `prompt-writing.md` 配合。逐项考虑，但只询问重要且无法安全推断的内容。

| 要素 | 判断重点 |
|---|---|
| 核心任务 | 最终要交付什么 |
| 上下文与输入 | 哪些背景、变量或素材会改变答案 |
| 成功与证据 | 怎样算正确；需要什么事实、引用或测试支撑 |
| 输出契约 | 必须包含什么；结构、长度和删减优先级 |
| 行动权限 | 只回答、提出方案，还是可以实际执行；何时确认 |
| 工具策略 | 需要哪些工具、何时用、停止与失败条件 |
| 必要约束 | 安全、合规、业务禁区和关键例外 |
| 示例 | 是否编码产品要求或修复已测得的失败 |
| 验证方式 | 用哪个真实场景和标准试跑 |
| 角色 | 专业视角或语气能显著改善结果时才指定 |

不要逐项补齐成冗长问卷。复杂分析任务可要求先检查证据和假设，但不要要求展示隐藏推理过程。发现用户选择与自由描述矛盾时，当场指出并校正。
